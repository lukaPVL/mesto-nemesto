## Публикация проекта
Проект автоматически собирается и публикуется на GitHub Pages при каждом пуше в ветку `main`.

**Ссылка на проект:** https://lukapvl.github.io/mesto-production/

### Команда для ручной публикации
Если вам необходимо запустить сборку и деплой вручную без внесения изменений в код, это можно сделать через вкладку **Actions** в GitHub репозитории:
1. Перейти в раздел **Actions**.
2. Выбрать воркфлоу **Deploy to Public Pages Repository**.
3. Нажать кнопку **Run workflow**.

### Преамбула
Чтобы запустить проект, обязательно понадобиться выполнить npm install с установленным Node.js
